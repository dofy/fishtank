# 历史版本验证与兼容记录

从更新日志移出的技术记录，保留各次发布时的验证范围。最新线上状态见 [部署记录](DEPLOYMENTS.md)。

## [1.7.0] - 2026-10-19

### 验证与发布

- 写实鱼体保留 19×9 网格与原有动作公式，通过原生网格合批、按列计算摆动、固定可见滤镜范围，减少重复工作；保留滤镜分辨率、抗锯齿与水下效果。
- 同一份 12 条鱼、9 件造景的黑夜快照复测，桌面与沉浸场景的平均 JS 绘制/提交开销降低约 36%；小屏模拟本轮没有改善，GPU 耗时也没有一致下降，不代表所有设备或耗电都有收益。测量方法与原始数据见 [写实优化复测](docs/PIXI_OPTIMIZATION.md)。
- 58 项回归测试、类型检查及生产构建通过，覆盖全部 29 种鱼的动作公式、暂停与恢复、固定重放、异步 GPU 计时、异步启动前后注册 Service Worker、LCD 仪式与放电网格、明暗配色及既有玩法规则。浏览器验证双风格、昼夜、投喂、受惊、电鳗放电、造景保存、繁育与 Canvas 回退。
- 开发模式保留 `?pixiLab=1` 对照工具、示例鱼群和性能采样；生产构建只提供正常游戏与 Canvas 回退，不显示实验工具栏。
- 应用、包、README 与数值文档同步为 `1.7.0`，Service Worker 缓存修订为 `fishtank-pwa-v1.7.0-r6`，保留两个自定义域名；部署标识与线上验证结果见 [部署记录](docs/DEPLOYMENTS.md)。

## [1.4.7] - 2026-10-19

### 开发与兼容说明

- 补齐 `0+2`、`0+3`、`0+4`、`0+5`、`1+5`，沿用本项目既有的“亲代星级总和相同，概率相同”规律；原有已配置概率不变，补全值并非已核实的原作概率。
- 总经验先按品阶倍率四舍五入，出生领取一半并向下取整，成年领取余数；合成鱼成年领取全额。
- 沿用现有存档格式和存储键。旧鱼缺少出生经验记录，无法区分繁育或合成来源，保留其全额成年结算；历史上误点亮的品阶无法与真实发现区分，因此不自动撤回。
- 缺少品阶历史的旧存档优先从现存鱼恢复；只有某鱼种完全没有品阶证据时，才沿用旧版品阶 1 兜底。
