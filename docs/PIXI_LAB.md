# 本地鱼缸对照实验

从 v1.7.0 起，PixiJS 用于默认鱼缸渲染。普通游戏入口已默认使用 PixiJS，保留 Canvas 自动回退与 `?renderer=canvas` 手动入口。现有玩法、两种主题与存档格式保持不变；本页介绍额外的开发对照工具。

## 打开与比较

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，并加上 `?pixiLab=1`，默认端口为 <http://localhost:5173/?pixiLab=1>。

- **滑动对照**：左侧 Canvas，右侧 PixiJS。分界只裁切画面；两边使用同一套鱼的位置、朝向、投喂和受惊状态。拖动分界，观察同一条鱼的差别。
- **Canvas 原版 / PixiJS 样例**：单独查看一种渲染方式，不重置鱼的位置。未显示的渲染器暂停绘制。
- **水下光纹**：仅控制 PixiJS 写实主题的折射、光纹与漂浮微粒；LCD 保持单色点阵，不使用水波滤镜。
- **鱼体摆动**：仅控制 PixiJS 的身体动画与转身过渡；关闭后鱼仍沿原来的路线移动。系统「减少动态效果」也会关闭新增的摆动和环境运动。
- **观察示例鱼群**：暂时显示 12 种不同鱼形与 9 件造景，包括电鳗、水母、海马、蝠鲼、海龟，以及海草、贝壳和吊灯。示例鱼和装饰拖动仅存在于内存，不加入背包；下方繁育、合成等操作仍使用真实本地存档。取消勾选即可回到自己的鱼缸。
- **运行性能对照 / B**：按 Canvas → PixiJS → PixiJS → Canvas 分别播放固定场景，各轮预热 90 帧后采样 180 帧。可取消或下载 JSON。沉浸模式下也能按 `B` 开始，退出沉浸后查看结果；窗口、主题、鱼群、造景或页面可见状态变化时自动取消，避免混入不同工作量。
- 在游戏**设置**中切换写实 / LCD、日间 / 黑夜；仍可使用原来的快捷键与沉浸模式。
- 点击「返回常规游戏」退出实验。实验开关不保存；正常游戏操作仍按原来的方式保存进度。

生产构建中，`import.meta.env.DEV` 会移除实验工具栏导入；正常游戏仍默认启用 PixiJS，方便使用 `pnpm preview` 检查正式构建。`?pixiLab=1` 只在开发服务中显示对照工具。两个线上域名均使用默认渲染，追加 `?renderer=canvas` 可回退。开发入口不会注册额外的 Service Worker。

## 实现范围

| 部分 | 当前方案 |
| --- | --- |
| 游戏规则与鱼的移动 | 复用原来的 `GameState`、`App` 与 `Scene`，不改繁育、合成或收集规则 |
| 写实鱼形 | 复用现有绘制函数生成纹理，19×9 网格通过原生合批绘制；按列计算不同体型的摆动、鳗鱼波动、水母舒缩和转身过渡 |
| LCD 鱼形 | 沿用原来的点阵采样，姿态纹理最多更新 8 次/秒，最近邻显示，不拉伸点阵、不添加彩色滤镜 |
| LCD 放电 | 单色不透明方格与逐格轻颤，按主题网格对齐；减少动态效果时固定电光姿态，六次点击触发及眩晕规则不变 |
| 收回小鱼 | 共用 Scene 的 0.55 秒局部游离；写实缩小淡出，LCD 保留网格尺寸、分级点阵消隐。减少动态效果时改为 0.12 秒原地消隐，立即释放游戏名额，再次放入复用原对象 |
| 鱼景互动（v1.8.0） | Scene 共用海草停歇、穿拱与随机 2–5 条同种结群；穿拱时造景前景临时遮挡，结束后恢复原层次；河豚点击后短暂鼓起，LCD 使用四档不透明轮廓，保持整数网格 |
| 写实环境 | PixiJS 矢量图形绘制水色、远礁、沙床、两种背景鱼群、灯架、灯罩、彩灯与气泡；静态几何复用，运动通过场景对象变换实现 |
| LCD 环境 | 四顶点 GPU 点阵面板绘制背景、远礁、沙床和灯光，保留单色配色与点阵网格 |
| 18 件造景 | 复用原来的轮廓公式，生成原生矢量路径；有限动画帧缓存为 GraphicsContext，LCD 采样为单色原生方格；支持顶挂、镜像、悬停高亮和左右拖拽 |
| 鱼食、浮游生物与水花 | 原生 Graphics / 场景对象绘制；浮游生物同时最多 3 只，过期或被吃掉即释放节点。LCD 使用整格单色图形，沿用 Scene 的投喂、进食、落水与受惊状态 |
| 水下效果 | 写实主题使用 WebGL 滤镜做轻微折射与光纹，叠加缓慢漂浮的微粒 |
| 电鳗互动 | 共用原来的放电和眩晕状态，PixiJS 绘制电弧与全缸闪光；原生灯光跟随灯色变化 |
| 异常处理 | WebGL 初始化失败或上下文丢失时显示 Canvas；上下文恢复后继续对照 |
| 资源 | 同种鱼、同品阶共用纹理；移出鱼缸或切换主题后释放不用的纹理与网格；小尺寸渐变纹理按配色缓存，关闭页面时释放 |

随机结群、浮游生物和河豚鼓起为临时观赏状态，不写入存档；投喂、受惊、放电、收回及对应造景拖动/移除会中断，系统“减少动态效果”会停用它们。

LCD 退场中的每条鱼独占一张小纹理，避免影响同种同品阶的其他鱼；密度变化只更新这张纹理，结束或取消时释放，不按动画帧增加缓存项。临时退场状态不写入存档，也不参与进食、受惊或放电。

已经移除整缸 Canvas 背景采样和每秒 15 次的大图上传。鱼形仍复用既有绘制函数生成小纹理，LCD 鱼形姿态仍按每秒最多 8 次更新；造景几何、水下背景和互动效果均由 PixiJS 原生渲染。PixiJS 的渐变会生成并缓存小尺寸渐变纹理。不同渲染器的阴影、曲线细节和动画方式并非逐像素一致，游戏界面中的肖像与结果弹窗仍使用原来的渲染器。

日常工具栏显示每帧 **JavaScript 绘制 / 提交命令的平均耗时**，不能当成 GPU 总耗时。自动对照工具分轮运行、固定重放场景，另用非阻塞 GPU timer query 记录 PixiJS GPU 时间。Canvas 的 GPU 时间由浏览器内部管理，无法直接取得；浏览器不支持扩展或发生 disjoint 时不会编造结果。测量方法、原始数据与本机结论见 [历史性能记录](PIXI_PERFORMANCE.md)和[最新优化复测](PIXI_OPTIMIZATION.md)。正式构建已做本地功能检查；手机真实硬件、长时间耗电与生产包的性能数字仍需另行测量。

## 验证

```sh
pnpm typecheck
pnpm test
pnpm build
```

浏览器检查：两种主题的昼夜切换、三种对照模式、滑块和效果开关、示例鱼群与真实鱼缸切换、投喂 / 受惊 / 电鳗放电、装饰拖动、繁育与合成、手机尺寸、沉浸模式、减少动态效果，以及 WebGL 失效回退。

v1.8.0 发布验收：125 项测试、类型检查与生产构建通过。四组写实/LCD × PixiJS/Canvas 定点场景验证停歇、穿拱遮挡及恢复、结伴、鼓起与减少动态效果；LCD Canvas 水域保持四种不透明色，GPU 点阵纹理保持 0/255 alpha。完整范围见 [验证记录](RELEASE_VERIFICATION.md)。

此前 v1.7.0 渲染迁移已验证 65 项测试、类型检查与生产构建。测试覆盖重放不修改原数据、ABBA 采样与预热剔除、百分位统计、18 件造景无 Path2D 输出、异步 GPU 计时 / disjoint 作废，全部鱼形的网格公式回归，以及收回小鱼的生命周期、取消、互动隔离和点阵裁剪。浏览器检查两种主题昼夜、18 件造景的双风格、320 / 390 / 1280 宽度、2 倍像素密度、沉浸模式、投喂、受惊、电鳗六次点击放电、原生灯色与拖拽；减少动态效果会静止新增的背景运动。示例鱼和造景不写入真实存档。WebGL 丢失时回退 Canvas，恢复后继续原生渲染。窗口变化会取消性能采样。生产构建不包含实验工具栏；最新同场景优化前后数据见 [写实优化复测](PIXI_OPTIMIZATION.md)。

主要入口：`src/lab/pixi-lab.ts`；GPU 鱼体：`pixi-tank.ts`；背景与造景：`native-environment.ts`；点阵面板：`native-lcd.ts`；几何适配：`vector-path.ts`；固定重放与计时：`benchmark.ts`、`gpu-timer.ts`。原有鱼形的纹理接口仍为 `Renderer.fishFrame()`。
